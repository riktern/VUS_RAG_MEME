# Multimodal Image Search RAG System

## Описание проекта

Проект представляет собой мультимодальную систему поиска изображений на основе векторной базы данных и больших языковых моделей (LLM).

Система позволяет:

* Выполнять семантический поиск изображений по текстовому описанию.
* Автоматически анализировать изображения с помощью Gemini Vision.
* Извлекать текстовую и визуальную информацию из изображений.
* Сохранять эмбеддинги изображений в Qdrant Cloud.
* Добавлять изображения как автоматически через LLM, так и вручную с пользовательским описанием.
* Выполнять поиск через Telegram-бота.

## Основные возможности

### 1. Поиск изображений

Пользователь отправляет текстовый запрос:

```text
кот возле окна
```

Система:

1. Строит эмбеддинг запроса.
2. Выполняет поиск в Qdrant.
3. Находит наиболее похожие изображения.
4. Возвращает пользователю до 3 наиболее релевантных результатов.

---

### 2. Добавление изображения через Gemini Vision

Пользователь отправляет изображение.

Gemini выполняет:

* OCR текста на изображении.
* Визуальный анализ содержимого.
* Генерацию структурированного описания.

Пример результата:

```text
OCR:
В конце концов все наладится

DESCRIPTION:
На изображении изображен кот,
лежащий на диване возле окна.
```

После этого:

* Создается эмбеддинг.
* Данные сохраняются в Qdrant.

---

### 3. Добавление изображения по пользовательскому описанию

Пользователь отправляет:

* изображение;
* собственное описание.

Пример:

```text
Мем про кота возле холодильника
```

В этом режиме Gemini не используется.

Вектор строится непосредственно по описанию пользователя.

## Формат хранения данных

В Qdrant сохраняются:

```json
{
  "image_name": "cat.jpg",
  "content": "Описание изображения..."
}
```

Вектор:

```python
[0.123, -0.441, ...]
```

Сами изображения хранятся локально на сервере.
